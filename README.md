# Автоматизированные тесты системы управления проектами YouGile

## Документация проекта

Описание базового синтаксиса записи и форматирования.

Проект содержит автоматизированные тесты для проверки функциональности системы управления проектами YouGile.

### Структура проекта:

* Папка Test_API — API-тесты
* Папка Test_UI — UI-тесты

### Проект использует следующие библиотеки и синтаксис:

* Python: Основной язык программирования для написания тестов.
* Selenium: Библиотека для автоматизации взаимодействия с веб-браузером.
* Pytest: Фреймворк для написания и запуска тестов.
* Allure: Инструмент для генерации отчетов о выполнении тестов.
* requests: Для отправки HTTP-запросов.
* selenium.webdriver: Для автоматизации взаимодействия с браузером.

## Форматирование кода

Код форматируется в соответствии с PEP 8 (стиль написания кода на Python). Все шаги теста размечаются с помощью @allure.step или with allure.step для улучшения читаемости отчетов.

## Запуск тестов

Тесты запускаются командами:

python3 -m pytest
python3 -m pytest -m api
python3 -m pytest -m ui

## Инструкция по запуску тестов для формирования отчета Allure

1. Установите необходимые зависимости:
python3 -m pip install pytest requests selenium allure-pytest

2. Запустите тесты с генерацией отчета Allure:
python3 -m pytest --alluredir=./allure-results

Эта команда запустит все тесты и сохранит результаты в директорию ./allure-results.

## Инструкция по просмотру сформированного отчета Allure

После завершения тестов, чтобы просмотреть отчет, выполните команду:

allure serve ./allure-results

Эта команда запустит локальный сервер и откроет отчет в браузере.
